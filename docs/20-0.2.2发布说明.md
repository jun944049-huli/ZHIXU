# 知序 0.2.2

2026-10-24

对话中的工作状态可以同步到真实任务与项目，修复回复里的协议字段和转义换行。

- 兼容带代码围栏、说明文字或双重编码的模型 JSON 回复；历史消息中的 `\n`、`actions` 尾巴恢复为可读内容。损坏的结构只恢复文字，不执行其中的动作。
- 说明“维修部分全部完成”“设备部署正在进行中”等状态时，使用模型匹配实际项目、任务和里程碑 ID，同步更新已有记录，不重复新建任务。问题、假设与有歧义的内容保留待确认操作。
- 里程碑编辑支持勾选关联任务；关联任务全部完成后节点完成，撤销完成后重新打开。仍有关联任务未完成时，不允许直接把节点标为完成。
- 项目按任务完成比例计算进度，更新未完成数量、整体状态和下一节点；尚有里程碑未完成时，不将项目记为 100%。仅维修完成不会自动完成设备部署、联调或验收。
- 旧版生成的空“未安排”占位不参与里程碑与完成度统计，原记录保留；手动创建的节点仍按实际状态计算。
- 今日与侧栏数量、逾期提醒、已关联附件任务、等待事项、项目记录与报表同步；前几天安排、今天完成的任务也计入今日日报。
- 按任务 ID 隔离同名任务和不同项目；请求期间数据已变化时拒绝过期结果，保存失败恢复整组状态，已执行的同步不能重复执行。
- 已同步详情默认收起，回复展示项目、任务完成数量、进度与下一步，保留所用模型名称。

验证通过：构建与类型检查、71 项单元测试，以及打包后的对话、主要页面、逾期操作和附件回归。覆盖 7 个主要页面、6 个项目页签、6 类报表；对话验证真实 IPC / 本地模拟供应商 HTTP、部分与全部完成、项目进度、里程碑、完成日期报表、窄窗口、模型切换及重启保留。附件验证 Office / PDF、49 MB 文件及失败后保留选中。

安装 `Zhixu-0.2.2-Windows-Setup.exe`，沿用原“知序”程序、桌面快捷方式与本机数据。历史聊天不会自动修改任务；更新后重新说明需要同步的工作状态。
