## 验证

- `npm test`：30 项数据库、连接器、供应商接口、业务逻辑和导出文件格式回归全部通过。
- `npm run build`：TypeScript 检查与生产构建。
- `npm run test:interfaces`：遍历 7 个主页面、6 个项目页签、6 类报表，检查按钮有处理函数且不再落入演示提示。
- 实际操作任务改期与状态、计时、等待事项、插单确认、收件箱忽略恢复与拆分归档、风险与里程碑、自定义单选字段、文本导入、报表编辑与重新生成。
- 四种报表文件实际生成，检查 PDF 文件头、DOCX 内部文件和 XLSX 中文内容；JSON 工作数据导出排除连接凭据，数据库备份实际打开验证。
- `npm run test:desktop`：任务、项目、连接器导入、持久化、重启及凭据加密回归；打包程序使用独立测试资料运行同类检查。
- `npm run test:web`：项目增删和刷新恢复、全部主页面的手机宽度检查。

测试使用独立临时数据库、模拟接口和假凭据，不修改日常工作资料。
按钮检查与回归测试不能保证所有输入和外部服务都没有问题。

## 使用范围

- 桌面后端负责本机 SQLite、连接器请求与文件导出；没有云端账号服务或跨设备同步。
- 完整大模型对话未接入；已配置供应商仅用于润色，本地指令支持有限的结构化操作。
- 工作流仅保存草稿；没有后台执行、自动定时同步或系统通知推送。
- 支持 TXT / MD / CSV 文本，每个文件不超过 512KB，文本库合计不超过 2MB；暂不解析图片、PDF、Word、Excel 二进制附件。
- 扩展字段的人员、关联值目前按文本保存；系统字段由业务模型管理。
- 飞书、IMAP、ICS 支持手动读取；钉钉、企业微信支持认证测试，尚未接收消息；其他连接器未接入。
- 外部连接器仍需用户提供真实应用权限和凭据。回归不代替用户环境中的实际授权测试。
- 浏览器与桌面存储独立。Word、Excel、PDF 和 SQLite 备份由桌面版提供，浏览器只导出工作数据与文本格式。
- 首次启动带示例项目、任务及原文；统计依据当前本地记录，示例仍会计入，不能视为自动采集的数据。
