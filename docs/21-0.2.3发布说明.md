# 知序 0.2.3

2026-10-24

附件分析、查看与保存形成完整流程，减少重复和过细的任务。

- 修复保存成功后重新打开原弹窗的问题。保存修改、保存到项目后关闭弹窗，回到对话页。
- 分析完成后自动回到对话页，展示摘要、任务概览和“详细”入口。点击“详细”定位关联项目并打开可编辑的附件清单；同一附件更新原摘要，不堆积重复结果。
- AI 按交付物或执行阶段整理相关工作，通常为 4 至 8 项任务。标题保持简短，具体步骤、要求和验收标准保存在“详细”字段，可在附件及任务编辑页修改。
- 已有附件任务可勾选后填写标题，使用“合并所选”。合并保留原始任务记录、详细要求和已完成状态，重映射里程碑、等待事项及计时记录的任务引用。
- 合并前后按原工作项计算进度，不因缩减任务数量误改完成比例；完成整项时同步其原工作项、里程碑、项目进度、附件状态及提醒。
- 不同项目、负责人、截止日期或里程碑的任务不能合并。过期引用、重复分组和其他附件的任务会阻止保存，避免误改无关工作。
- 重新分析使用已有任务 ID 保留关联关系，未覆盖的已有任务继续保留；修改及合并等待保存后生效。新项目仍需明确确认才创建。
- 保存失败恢复项目、任务、附件与对话状态，保留编辑内容供重试。待估时任务可用 0 小时保存详细清单。

验证通过：构建、类型检查与 76 项单元测试；打包后的附件、AI 分析、对话及主要界面回归，覆盖 7 个主要页面、6 个项目页签和 6 类报表。附件覆盖 Office / PDF、49 MB 文件、超过 50 MB 拒绝且保留选中、失败重试、摘要与详情跳转、合并后的状态及重启保留；AI 分析通过真实 IPC 与本地模拟供应商 HTTP 验证重新分组、原始进度保留及整项完成联动。浏览器附件回归亦通过。

沿用原“知序”桌面程序、快捷方式与本机数据。已有项目不会在更新时自动合并；打开附件后重新分析或勾选合并，再保存到项目。
