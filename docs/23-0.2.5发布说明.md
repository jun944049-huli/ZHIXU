# 知序 0.2.5

2026-10-24

项目进展有连续记录，任务截止日期可直接选择。

- 任务列表增加备注入口。编辑任务时可填写本次进展备注和完成百分比，每次保存追加一条记录，原有备注不再被覆盖。
- 任务完成、重新打开及进度变化均保留状态记录；每条新记录显示年月日、时分秒、来源及记录人。历史备注没有可靠时间时标注“时间未记录”，不伪造记录日期。
- 对话使用所选模型，将口语化进展整理成简洁的项目语言，分别追加到对应任务及项目“进展记录”；可展开查看原话，保留完整历史。
- 仅补充任务或项目备注时，保留已有任务状态、已完成的子任务及项目进度。有歧义、询问和假设的更新继续等待确认。
- 项目编辑支持补充项目备注；合并相关任务后，保留原任务的备注记录。记录存入原有本地数据库，重启后继续可见。
- 原“截止说明”改为“截止日期”，支持日期选择和清除，拒绝无效日期；旧截止说明单独保留，修改后同步逾期提醒。
- 沿用原“知序”桌面程序、快捷方式与本机数据。

## 验证

- TypeScript 类型检查、生产构建及 82 项自动化测试通过。
- 打包后的桌面程序通过备注追加、原备注保留、日期选择与清除、模型接口同步、重启留存及窄屏布局检查。
- 打包后的对话与逾期流程通过回归测试，包括任务、里程碑、项目进度与提醒同步，改期和完成操作互不误伤。
- 文档分析、任务合并与桌面基础流程通过检查。模型接口测试使用隔离数据和测试服务，不修改本机实际项目。
