# 小鱼 · 视觉规范

> 文档版本：v0.3  
> 更新日期：2026-10-21  
> 对应实现：`prototype/styles.css`

---

## 1. 视觉概念

**关键词：白纸、编辑感、安静、掌控、可解释。**

小鱼不是 SaaS 仪表盘，也不是游戏化待办。它更像一本被认真排版的工作手册：

- 主背景为纯白，用细边框和浅灰面板建立层次，不靠大面积色块。
- 文字接近墨黑，不用纯黑。
- 主色是钴蓝，只在“行动”和“当前”出现。
- 风险色克制使用，避免红色轰炸。
- 信息密度高，但通过留白、细线、字号层级保持呼吸。
- 数据与叙述有明确的视觉分层。

### 1.1 设计隐喻

| 隐喻 | 视觉表达 |
| --- | --- |
| 纸 | 白色背景、细边框、低对比阴影 |
| 账簿 | 数字用 tabular-nums，事实与叙述分栏 |
| 编辑台 | 大标题、eyebrow、衬线感节奏 |
| 控制台 | 产能条、状态点、操作卡 |

### 2.3 用色规则

1. 一屏内主色面积不超过 10%。
2. 红色只用于风险、逾期、破坏性操作。
3. 同一行不同时出现两种以上状态色。
4. 深色主题下不使用纯白文字，避免刺眼。
5. 图表色顺序：钴蓝 → 紫 → 绿 → 琥珀 → 红。

## 3. 字体

```css
--font: "Inter", "SF Pro Text", "Segoe UI Variable", "Segoe UI",
        "PingFang SC", "Microsoft YaHei", sans-serif;
```

| 层级 | 字号 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| H1 | 30px | 720 | 1.18 | 页面标题 |
| H2 | 16px | 680 | 1.3 | 区块标题 |
| H3 | 13px | 650 | 1.4 | 卡片标题 |
| Body | 13.5px | 400 | 1.5 | 正文 |
| Small | 11.5px | 400 | 1.45 | 辅助说明 |
| Tiny | 10.5px | 400 | 1.4 | 元信息 |
| Eyebrow | 10.5px | 700 | 1.2 | 全大写标签，字距 .12em |

规则：

- 大标题使用负字距 `-0.035em`，形成编辑感。
- 数字使用 `font-variant-numeric: tabular-nums`。
- 中文正文不使用过细字重，最低 400。
- 标签全大写仅用于英文 / 拼音 eyebrow，不用于中文长句。

## 4. 空间与形状

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius` | 12px | 卡片、弹层 |
| `--radius-sm` | 8px | 按钮、输入框 |
| 侧边栏宽 | 244px | 桌面 |
| 侧边栏窄 | 214px / 72px | 平板 / 小屏 |
| 顶栏高 | 62px | 固定 |
| 内容最大宽 | 1460px | 主区 |
| 页面内边距 | 26px 30px 72px | 桌面 |

间距节奏：4 / 6 / 8 / 10 / 12 / 16 / 20 / 24 / 32。

阴影：

```css
--shadow-sm: 0 1px 1px rgba(25,26,29,.03), 0 2px 4px rgba(25,26,29,.03);
--shadow-md: 0 12px 32px rgba(25,26,29,.10);
--shadow-lg: 0 24px 64px rgba(25,26,29,.18);
```

规则：

- 卡片默认只用 `shadow-sm`，靠边框建立层次。
- 弹层用 `shadow-lg`，背景加模糊遮罩。
- 不使用彩色阴影，主按钮除外。

## 5. 布局

### 5.1 桌面（> 1280px）

```text
┌────────────┬──────────────────────────────────────────────┐
│ 侧边栏 244 │ 顶栏 62                                      │
│            ├──────────────────────────────────────────────┤
│ 品牌       │ 页面标题 + 操作                              │
│ 工作台     │                                              │
│ 导航       │ 主内容（最大 1460）                          │
│ 项目       │                                              │
│ AI 状态    │                                              │
│ 用户       │                                              │
└────────────┴──────────────────────────────────────────────┘
```

### 5.2 对话页

```text
┌──────────────────────────────────────────────┬──────────────┐
│ 聊天线程（可滚动）                           │ AI 正在参考  │
│                                              │ 可执行操作    │
│ 用户气泡 / AI 气泡 / 操作卡                  │ 安全边界      │
├──────────────────────────────────────────────┤              │
│ 快捷指令                                     │              │
│ 输入框 + 参考范围 + 模型 + 发送              │              │
└──────────────────────────────────────────────┴──────────────┘
```

- 主聊天卡片高度：`calc(100vh - 196px)`，最小 560px。
- 对话页标题区只保留 eyebrow 与 H1，不再放说明段落，减少顶部占用。
- 右侧栏宽 292px，1280px 以下 250px，1120px 以下隐藏。
- 输入区固定在卡片底部，线程独立滚动。

### 5.3 响应式断点

| 断点 | 变化 |
| --- | --- |
| ≤ 1280px | 项目卡片两列；报表右栏隐藏；对话右栏收窄 |
| ≤ 1120px | 侧边栏 214px；今日 / 项目详情单列；对话右栏隐藏 |
| ≤ 920px | 侧边栏 72px 图标模式；收件箱单列；连接器三列 |
| ≤ 680px | 页面单列；H1 25px；连接器两列；对话输入简化 |

## 6. 组件规范

### 6.1 按钮

| 类型 | 高度 | 用途 |
| --- | --- | --- |
| 默认 | 32px | 次级操作 |
| Primary | 32px | 主行动，一屏最多一个 |
| Small | 28px | 卡片内操作 |
| Large | 38px | 弹层主行动 |
| Icon | 32 / 26px | 工具操作 |

- 圆角 8px，边框 1px。
- Primary 使用主色实底，hover 加深。
- Ghost 无边框，hover 出现浅底。
- 危险操作只用红色文字，不默认红底。

### 6.2 卡片

- 背景 `--surface`，边框 `--line`，圆角 12px。
- 标题区 `panel-head`：13px / 650，底部细线。
- 内容区 `panel-body`：16px 内边距。
- 卡片内不嵌套超过两层卡片。

### 6.3 任务行

- 左侧复选框，中间标题与元信息，右侧估时 / 优先级。
- 完成后标题删除线、整体降透明度。
- 元信息使用项目色点 + 项目名 + 截止 + 估时。
- 聚焦任务左侧加主色竖线，不使用整行高亮。

### 6.4 对话气泡

| 角色 | 背景 | 文字 | 圆角 |
| --- | --- | --- | --- |
| 用户 | `--accent` | `--accent-ink` | 12px，右上 4px |
| AI | `--surface-2` | `--ink` | 12px，左上 4px |

- 用户消息右对齐，AI 左对齐。
- 最大宽度：AI 680px / 84%，小屏 92%。
- 元信息 9.5px，弱化。
- 气泡内不放大段表格；复杂内容用操作卡。

### 6.5 AI 操作卡

- 左侧 3px 主色边，背景 `--surface`。
- 头部：图标 + 标题 + 状态标签。
- 变更项：`标签 62px + 变更前后值`，虚线分隔。
- 底部操作区：确认执行 / 只更新进度 / 取消。
- 已执行：左边变绿，条目打勾。
- 已取消：整体降透明度，左边变灰。

### 6.6 连接器卡片

- 三组标题：内容与沟通 / 工作系统 / 插件与扩展。
- 每个连接器：方形字母标记、名称、状态、最近同步。
- 已连接：绿色状态点；未连接：灰色状态点。
- 组标题右侧显示 `已连接 / 总数`。

### 6.7 输入框

- 高度 32px，圆角 8px，边框 `--line`。
- focus：主色边框 + 3px `--accent-soft` 外圈。
- 错误：琥珀色边框，不直接用红色。
- 对话输入使用大圆角容器，内部 textarea 无边框。

### 6.8 标签 / Chip

- 高度 21px，圆角 6px，字号 10.5px。
- 语义色：accent / green / amber / red / violet。
- 对话快捷指令使用 25px 高度，带边框，hover 变主色。

### 6.9 连续记忆标识

- 位于对话页标题右侧，非按钮。
- 高度 26px，圆角 7px，背景 `--surface-2`，文字 `--ink-3`。
- 图标使用图层 / 记忆语义，颜色用 `--green`。
- 文案：`连续记忆 · 项目 / 任务 / 工作流`。
- 不使用“新对话”按钮；对话默认延续上下文。

### 6.10 内容润色

- 入口：仅输入区左下角「润色」文字按钮，快捷指令行不重复放置。
- 弹层宽度 760px，左右双栏：原文 / 润色后。
- 语气 chip：简洁 / 正式 / 有说服力 / 温和。
- 语气下方显示润色来源：本地规则 / DeepSeek 润色中 / DeepSeek / 失败回退。
- 未配置 Key 时右侧出现「配置 DeepSeek」按钮，点击进入个人资料与设置。
- 预览区背景 `--surface-2`，最小高度 158px。
- 底部操作：恢复原文 / 取消 / 复制 / 替换输入框。
- 底部绿色提示条说明：只调整结构与语气，不新增具体事实。

### 6.11 自定义快捷指令

- 快捷指令行左侧为 chip 列表，右侧固定「+ 自定义」虚线按钮。
- 自定义按钮不随 chip 横向滚动，始终可见。
- 弹层宽度 760px；每行三列：按钮名称 / 完整指令 / 删除。
- 名称列 132px，指令列自适应，删除列 28px。
- 底部操作：恢复默认 / 取消 / 保存快捷指令。
- 说明条：点击只填入输入框，不会自动发送；建议 3–6 条。

### 6.12 项目表与自动写入回执

- 项目详情新增「项目表」标签，表格四列：时间 / 记录 / 来源 / 记录人。
- 记录主文本使用润色后文本；原文以更小、更浅的字号显示在下方。
- 表头沿用风险表的浅灰底、9px 大写字距；表格最小宽度 560px，窄屏横向滚动。
- 标签右侧显示绿色「自动润色」chip，旁边提供「用对话记录」按钮。
- 对话中的写入回执为浅绿底细边框卡片：小鱼图标 + `已自动润色并写入 XX 项目表` + 「查看项目表」chip + 润色文本预览。
- 回执不替代 AI 操作卡：结构性变更仍在下方展示确认按钮。

### 6.13 个人资料与设置

- 左下角用户卡片打开，弹层宽度 560px，标题「个人资料与设置」。
- 字段顺序：姓名 / 角色 / 头像颜色。
- 不提供“头像缩写”和“助手名称”字段；头像缩写按姓名生成，助手名称固定「知序」。
- 保存后立即同步侧边栏品牌、对话标题、消息署名、页面标题与命令面板。

## 7. 图标

- 统一 24×24 viewBox，线性图标，`stroke-width: 1.8`。
- 默认尺寸 14–17px。
- 图标颜色跟随文字或状态色。
- 不使用彩色插画；品牌符号使用单线小鱼。
- 导航图标：今日太阳、对话消息、收件箱、项目网格、报表文件、画像用户、数据数据库。

## 8. 动效

| 场景 | 时长 | 缓动 |
| --- | --- | --- |
| 页面进入 | 300ms | `cubic-bezier(.2,.7,.3,1)` |
| 弹层进入 | 200ms | ease-out |
| hover | 150ms | ease |
| 按钮按下 | 100ms | translateY(1px) |
| AI 加载点 | 1000ms | 循环 |
| Toast | 200ms | ease-out |

规则：

- 动效只用于表达层级与状态，不做装饰性弹跳。
- 支持 `prefers-reduced-motion` 时关闭位移动画。
- 列表进入使用 30ms 递增延迟，最多 4 项。

## 9. 可访问性

- 正文对比度 ≥ 4.5:1；大标题 ≥ 3:1。
- 所有交互元素有 `:focus-visible` 外圈。
- 不用颜色作为唯一信息：状态同时有文字或图标。
- 键盘可完成：导航、捕获、命令面板、对话发送、弹层关闭。
- 图标按钮必须有 `aria-label`。
- 表单字段必须有可见 label。
- 暗色主题下避免纯黑背景 + 纯白文字。

---

## 10. 文案语气

- 像一位冷静的同事，不像客服。
- 说人话，不用“赋能 / 抓手 / 闭环”。
- 风险描述具体到人、时间、影响。
- AI 回复先给结论，再给依据。
- 不用感叹号堆情绪。
- 示例：
  - ✅ “测试库延迟 5 天，影响联调。建议今天 12:00 前升级。”
  - ❌ “风险预警！请尽快处理！！！”

---

## 11. 打印样式

- 隐藏侧边栏、顶栏、报表工具栏、模板列表、右栏、toast。
- 报表纸张全宽，去掉卡片边框与阴影。
- 背景纯白，文字纯黑。
- 保留事实层与叙述层的分节标题。

---

## 12. 设计检查清单

- [ ] 一屏只有一个主行动。
- [ ] 主色面积不超过 10%。
- [ ] 红色只用于真正的风险 / 逾期。
- [ ] 数字使用 tabular-nums。
- [ ] 卡片靠边框分层，不靠重阴影。
- [ ] 对话写操作有变更预览。
- [ ] 暗色主题下所有状态色可读。
- [ ] 键盘可完成核心流程。
- [ ] 空状态有下一步动作。
- [ ] 打印样式不包含导航。
