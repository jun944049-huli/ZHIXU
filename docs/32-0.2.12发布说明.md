# 知序 0.2.12

统一更新仓库名，清理公开仓库中的示例数据。功能与 0.2.11 相同。

## 变更

- 软件更新的仓库名改为 `ZHIXU`，旧版安装后可直接检查新地址。
- 源码、文档和测试中的示例项目与模型标识改为通用示例。
- 重新生成安装包与源码包，并更新校验值。

## 旧版本

为清理早期版本的源码示例，仓库已移除 0.1.8–0.2.11 的旧发布；已安装的旧版本仍可正常使用，需要重装时使用本版安装包。历史提交已重写，旧标签不再指向原记录。

## 升级

沿用原安装位置、桌面“知序”快捷方式和工作数据；已安装 0.2.9 及更高版本可在“设置 → 通用 → 软件更新”中更新。0.2.8 及更早版本需先覆盖安装一次。

更新源为 GitHub Releases（仓库公开），通常无需配置凭据；网络受限时可填写仅授予所需仓库 Contents 只读权限的 GitHub 令牌。
