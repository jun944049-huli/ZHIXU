# 知序 0.2.13

头像缩写改为按姓名自动生成，助手名称固定，设置里不再需要单独填写。

## 变更

- 设置 → 通用：移除“头像缩写”输入框，姓名输入框改为整行。
- 设置 → 通用：移除“助手名称”输入框，助手名称固定为「知序」。
- 头像缩写固定取姓名：中文取第一个字，英文取首字母（最多两个）。
- 修改姓名时，设置预览、侧栏工作台头像和对话头像立即按新姓名显示；此前保存的字符头像不迁移，打开应用后按姓名重新生成。

其他功能与 0.2.12 相同。

## 升级

沿用原安装位置、桌面“知序”快捷方式和工作数据；已安装 0.2.9 及更高版本可在“设置 → 通用 → 软件更新”中更新。0.2.8 及更早版本需先覆盖安装一次。

更新源为 GitHub Releases（仓库公开），通常无需配置凭据；网络受限时可填写仅授予所需仓库 Contents 只读权限的 GitHub 令牌。
