# 知序 0.2.1

2026-10-24

修复逾期清单中“改期 / 编辑”按钮随任务标题长短左右移动的问题。

- 桌面端固定两列操作区，两种按钮统一宽度、36 像素高度和间距，整列对齐。
- 任务名称在独立内容列内换行，不挤压按钮。
- 窄窗口将操作区移至标题下方，两按钮等宽并排。
- 仅调整逾期清单布局，保留任务编辑、改期、安排到今日和保存行为。

通过构建与类型检查、62 项单元测试、逾期操作回归及布局检查。浏览器覆盖 1440、960、640、496、390、320 像素，桌面覆盖 1440、960 像素，均检查浅色、深色模式、长短标题、按钮列对齐、尺寸及重叠和文字裁切。

下载 `Zhixu-0.2.1-Windows-Setup.exe`，正常关闭旧版后运行安装包，沿用原“知序”快捷方式、程序位置与本机数据目录。
