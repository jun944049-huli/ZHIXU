# 0.1.4 收件箱删除与桌面迭代

- 收件箱事项详情顶部新增“删除”按钮，确认弹窗显示具体事项标题。
- 取消删除不改变数据；确认后移出待处理列表，立即更新数量，并保存到本机。
- 删除记录保留原文及来源标识，可在“归档与回收站”恢复；重复同步不会重新导入同一条已删除来源。
- 已创建的任务不受影响；重复点击或失效的确认按钮不会删除另一条事项。
- 桌面只保留“小鱼测试版”快捷方式，目标固定为 `%LOCALAPPDATA%\Programs\Xiaoyu\Xiaoyu.exe`。
- 后续在固定位置覆盖迭代，不再往桌面增加版本程序和版本快捷方式。旧桌面文件移入项目的 `release/desktop-archive/` 留存。
- 现有工作数据继续使用 `%APPDATA%\Xiaoyu\workbench.sqlite`，不重建用户资料。

验证覆盖取消、确认、恢复、保存重载、来源去重及手机宽度布局；打包后使用独立测试资料运行界面回归。

若当前桌面会话截图超时，可设置 `XIAOYU_SKIP_SCREENSHOTS=1` 运行
`npm run test:interfaces`；它仅跳过截图，仍执行所有按钮操作与断言。
布局截图另由 `npm run test:web` 生成。
