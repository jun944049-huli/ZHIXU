# 小鱼 · 产品需求文档（PRD）

> 产品名：**小鱼**  
> 副标题：**PERSONAL WORKBENCH**  
> 文档版本：v0.3  
> 更新日期：2026-10-21  
> 对应原型：`prototype/`

---

## 1. 一句话定义

**小鱼不是待办清单，而是一套个人承诺与产能管理系统。**

它把老板、同事、会议、邮件里派来的事情，收拢成可承诺、可排期、可解释、可复盘的个人工作账本；同时让项目经理视角看到项目健康度、风险、依赖与资源挤占。

---

## 2. 为什么需要它

### 2.1 现有工具的三个断点

| 断点 | 现实表现 | 小鱼的回应 |
| --- | --- | --- |
| 任务散落 | 飞书、邮件、会议、Excel、Jira 各有一份 | 统一收件箱 + 原始来源层 `source_item` |
| 承诺失真 | 清单很长，但今天到底做不做得完没人知道 | 产能条、估时、WIP 上限、插单影响模拟 |
| 复盘困难 | 周报靠回忆，风险靠感觉 | 事实层与叙述层分离，结论可回到任务 ID |

### 2.2 目标用户

- 主要：同时承担多个项目、被多方派活的知识工作者。
- 次要：需要向上汇报项目健康度、风险与资源占用的项目经理 / 项目负责人。
- 典型画像：一人同时推进 4–8 个项目，日常在会议、IM、邮件之间切换。

### 2.3 用户真正想解决的问题

1. 我现在到底欠谁什么？
2. 今天做得完吗？再接一件事会挤掉什么？
3. 这个项目现在健康吗？风险在哪里？
4. 这周我到底做了什么，能不能说清楚？
5. 我的时间为什么总是不够？哪些承诺模式在重复？

## 3. 产品原则

1. **先事实，后叙述。** 完成、延期、风险、时间记录先形成事实；AI 只负责组织语言。
2. **先确认，后写入。** AI 可以读、可以提议，但任何写操作必须由用户确认。
3. **本地优先。** 默认数据在本机 SQLite；敏感项目可切换本地模型。
4. **不制造第二份真相。** 外部系统是来源，小鱼是个人承诺层；保留 `source_item` 原始数据。
5. **可解释。** 估时、优先级、画像结论都要给出依据，而不是黑箱分数。
6. **安静。** 不用红色轰炸用户；只在真正需要决策时打断。

---

## 4. 双视角

| 维度 | 执行者视角 | 项目经理视角 |
| --- | --- | --- |
| 核心问题 | 今天做什么、做不做得完 | 项目是否健康、风险是否可控 |
| 首页 | 今日工作台 | 项目组合 / 项目详情 |
| 关键对象 | 任务、等待、收件箱 | 里程碑、风险、干系人、依赖 |
| 时间尺度 | 今天 / 本周 | 项目全周期 |
| AI 用法 | 拆任务、更新进度、生成日报 | 生成周报、识别风险、模拟插单 |
| 成功标准 | 承诺兑现率、少加班 | 延期减少、风险提前暴露 |

> 两个视角共享同一套数据，不维护两份项目。

## 5. 核心对象

| 对象 | 说明 | 关键字段 |
| --- | --- | --- |
| `project` | 项目容器 | 名称、负责人、阶段、健康度、进度、起止时间 |
| `task` | 可执行承诺 | 标题、项目、估时、截止、优先级、状态、进度 |
| `waiting` | 等待他人的事项 | 事项、对象、项目、已等天数、影响 |
| `inbox_item` | 未确认的输入 | 来源、原文、AI 草稿、匹配项目、置信度 |
| `source_item` | 原始数据层 | 来源系统、原始 ID、原文、时间、作者 |
| `risk` | 项目风险 | 标题、概率、影响、等级、负责人、应对动作 |
| `report` | 日报 / 周报 | 周期、事实条目、叙述、风险、下周计划 |
| `profile` | 个人工作画像 | 时间分配、承诺模式、可解释结论 |
| `workflow` | 个人工作流 | 自然语言描述、解析后的规则、版本 |
| `chat_action` | AI 待执行操作 | 类型、目标对象、变更项、状态 |

### 5.1 扩展原则

- 核心实体不写死业务字段；项目、任务、联系人均支持自定义字段。
- 所有对象通过通用关联表连接，避免为每个集成加一张表。
- 外部数据先进入 `source_item`，再映射为核心对象；映射失败不丢原文。
- 连接器、自动化规则、AI 动作都注册在统一能力表中。

## 6. 功能需求

### 6.1 今日工作台

**目标：** 在 30 秒内回答“今天做什么、做不做得完、先做什么”。

必须包含：

- 日期控件：支持昨天 / 今天 / 明天 / 下周，也可指定任意日期。
- 问候、今日承诺总览。
- 产能条：会议、专注、弹性时间、承诺线。
- 具体工作时间段：例如 09:00–09:15 站会、09:15–11:15 深度工作，以及午休时间。
- 逾期 / 今日到期横幅（仅今天视图）。
- 任务三层分组：必须做、应该做、可以做；非今天视图按天或按周分组，只读展示。
- 每行任务显示：项目、估时、截止、优先级、AI 建议标记。
- 右侧栏：等待墙、今日会议、快速捕获入口。
- 支持勾选完成、查看项目、快速捕获。
- 支持“项目影响”。

验收标准：

- 今日承诺总时长与任务估时之和一致。
- 超过承诺线时，产能条与文案同时提示，而不是只变红。
- 勾选完成后，任务状态与计数即时更新。
- 切换日期后，任务列表、标题、摘要与预计投入同步变化；点「回到今天」恢复今日视图。
- 昨天视图区分已完成与未完成；下周视图按日期分组。

### 6.2 收件箱与快速捕获

**目标：** 让任何来源的事情在 10 秒内进入系统，不强迫当场分类。

必须包含：

- 全局快捷键 `Ctrl + Space` 打开快速捕获。
- 支持粘贴原文、选择来源（飞书 / 邮件 / 会议 / 手动）。
- AI 解析：任务标题、项目、截止、估时、优先级、子任务。
- 收件箱左侧列表、右侧原文与 AI 草稿对照。
- 显示匹配置信度与备选项目。
- 确认后进入今日 / 项目 / 等待，或保持未归属。

验收标准：

- 解析失败时保留原文，不丢输入。
- 用户可以修改 AI 草稿后再确认。
- 确认动作有明确 toast 反馈。

### 6.3 项目组合与项目详情

**目标：** 让项目经理视角看到“哪些项目需要我介入”。

项目组合必须包含：

- 项目卡片：健康度、进度、负责人、下一里程碑、风险数。
- 组合时间线：未来 6 周关键节点。
- 筛选：全部 / 健康 / 有风险 / 延期。

项目详情必须包含：

- 概览：目标、阶段、进度、健康度、关键指标。
- 任务：按状态分组，显示逾期与阻塞。
- 风险：概率 × 影响、等级、负责人、应对动作。
- 干系人：角色、影响力、最近互动。
- 项目表：自动接收对话中描述的项目记录，保留原文、润色后文本、来源与记录人。
- 文档与活动流。
- 时间投入：按工作类型拆分。

验收标准：

- 健康度颜色与风险数量一致。
- 项目详情中的任务状态与今日页同源。
- 风险等级变化能反映到项目卡片。
- 在对话里描述项目内容后，项目表新增一条记录，展示润色后文本，并可查看原文。

### 6.4 AI 对话工作台（独立页面）

**定位：** 不是通用聊天，而是“说一句话就执行”的工作台。

必须包含：

- 侧边栏独立入口「对话」，带 `AI` 标识。
- 聊天线程：用户消息、AI 回复、时间、模型标识。
- 欢迎语与示例指令。
- 输入区：多行输入、发送、参考范围选择、模型选择。
- 快捷指令：默认更新进展、把消息拆成任务、生成周报、检查能否接活；支持自定义。
- AI 操作卡：展示将写入的对象与变更前后值。
- 操作卡按钮：确认执行、只更新进度（按场景）、取消。
- 执行后状态：已执行 / 已取消，并追加一条结果消息。
- 右侧参考栏：项目字典、最近任务、今日产能、工作流版本、快捷指令数量。
- 安全边界提示：结构性写操作需确认，敏感项目可手动切本地模型。
- **连续记忆**：对话历史本地持久化，切换页面、刷新或重开应用后仍延续上下文；不提供“新对话”清空入口。
- **内容润色**：输入区左下角提供「润色」入口，支持简洁 / 正式 / 有说服力 / 温和四种语气；先预览，确认后替换输入框，不自动发送。
- **DeepSeek 润色**：设置中可填 DeepSeek API Key 并测试连接；润色时优先调用 DeepSeek，失败或未配置时回退本地规则。弹层显示当前来源（本地 / DeepSeek / 润色中 / 失败回退）。
- **项目表自动写入**：每次发送的描述只要匹配到项目或干系人，就自动润色并写入该项目「项目表」；原文保留，聊天里出现“已写入”回执与「查看项目表」入口。
- **自定义快捷指令**：快捷指令行最右侧提供「+ 自定义」，可新增、编辑、删除、恢复默认；名称短，内容为完整指令，点击只填入输入框，不自动发送。

对话能力范围（v1）：

| 意图 | 示例 | 行为 |
| --- | --- | --- |
| 更新进度 | “把星火联调更新到 80%” | 匹配项目与任务，预览进度变更 |
| 更新风险 | “测试库风险升到高” | 预览风险等级与应对动作 |
| 新建任务 | “把王总说的竞品分析拆成任务” | 生成任务草稿，确认后加入今日 |
| 生成报表 | “基于本周事实生成周报” | 跳转报表预览，不直接写文件 |
| 产能判断 | “今天还能接一个 2 小时任务吗？” | 给出挤占分析，不写入 |
| 未匹配 | “整理一下那个东西” | 追问项目，或先放收件箱 |

交互规则：

- `Enter` 发送，`Shift + Enter` 换行；中文输入法组合态不发送。
- 发送后显示“正在匹配项目、任务与工作流…”加载态。
- AI 必须先给出变更预览，用户确认后才写入。
- 取消不产生任何数据变更。
- 执行后保留操作卡，标记“已执行”，便于追溯。
- 切换页面、刷新或重开应用后，当前会话仍保留（localStorage 持久化）。
- 润色只替换输入框内容，不自动发送；用户仍需手动确认。
- 项目表记录自动写入，不打断对话；进度、风险、任务等结构性变更仍需确认。
- 快捷指令只填入输入框，不自动发送；用户可自由设计自己的常用指令。
- 模型选择保持手动：DeepSeek / OpenAI / Ollama，不做自动路由。

验收标准：

- 输入包含项目名或干系人时，能匹配到正确项目。
- 输入 `%` 进度时，按该数值更新；未给数值时给出建议值。
- 确认执行后，项目进度、任务进度、风险、等待墙同步变化。
- 取消后，数据不变，且出现取消确认消息。
- 刷新页面后，历史对话仍然存在，不需要重新开始。
- 润色可切换语气，预览结果与原文数字、截止时间一致，替换后不自动发送。
- 描述匹配到项目后，项目表自动新增记录；刷新后记录仍在。
- 快捷指令可新增、编辑、删除、恢复默认；保存后立即出现在输入框上方。
- 点击自定义快捷指令只填入输入框，不自动发送。
- 明暗主题下气泡、操作卡、输入区均可读。

### 6.5 我的工作流

**目标：** 让用户用自然语言描述自己的工作方式，AI 转成可执行规则。

必须包含：

- 自然语言输入框。
- 模板插入：会议行动项、每日收口、优先级判断等。
- AI 解析结果：规则列表，每条包含图标、标题、说明。
- 保存后显示版本号与更新时间。
- 规则作为 AI 对话的参考上下文。

验收标准：

- 未输入内容时不能解析。
- 解析后用户可保存或重新解析。
- 保存后刷新页面仍保留（localStorage / 后续 SQLite）。
- 对话页右侧显示当前工作流版本。

### 6.6 报表

**目标：** 让周报从“回忆作文”变成“事实 + 叙述”。

必须包含：

- 日报 / 周报切换。
- 事实层：完成、进行中、风险、时间记录，每条可回到任务 ID。
- 叙述层：AI 生成，可编辑。
- 风险与下周计划独立区块。
- 打印 / 导出预览样式。
- 模板选择与复制。

验收标准：

- 事实条目数量与底层任务一致。
- 叙述中的结论能对应事实条目。
- 打印时隐藏导航与工具栏。

### 6.7 工作方式画像

**目标：** 帮用户看见自己的承诺模式，而不是打分。

必须包含：

- 时间分配：会议 / 专注 / 沟通 / 其他。
- 承诺兑现率、估时偏差、上下文切换次数。
- 可解释结论：每条结论附依据。
- 建议动作：可关闭、可忽略。
- 隐私说明：画像只在本机计算。

验收标准：

- 每个结论都有“依据”入口。
- 不用单一分数评价用户。
- 建议不自动执行。

### 6.8 数据与集成

**目标：** 让用户按需接入数据源，而不是一次性配置所有系统。

连接器必须按三组展示：

| 分组 | 连接器 |
| --- | --- |
| 内容与沟通 | 飞书、钉钉、企业微信、邮件 IMAP、日历 ICS |
| 工作系统 | Excel / CSV、Jira、禅道、Webhook、GitHub |
| 插件与扩展 | 手动捕获、浏览器插件、快捷指令、n8n、MCP |

每组显示已连接数量。每个连接器显示：名称、状态、最近同步、能力说明。

还必须包含：

- 数据健康度：同步成功率、待映射条目、重复条目。
- 字段管理：核心字段 + 自定义字段。
- 自动化规则：触发条件、动作、启用状态。
- 导入 / 导出入口。

验收标准：

- 连接器分组不混排。
- 未连接连接器有明确“连接”动作。
- 自定义字段可新增、停用，不破坏已有数据。

### 6.9 个人资料、助手名称与工作台名称

**目标：** 让身份信息可编辑，头像缩写与助手名称自动确定，工作台名称自动派生。

必须包含：

- 左下角姓名 / 角色可点击编辑，打开「个人资料与设置」。
- 可修改：姓名、角色、头像颜色；头像缩写按姓名自动生成，不单独编辑。
- 助手名称固定为「知序」，不提供输入框；显示在侧边栏品牌、对话标题、消息署名、页面标题、命令面板与报表生成说明。
- 不提供“工作区名称”输入框。
- 左上角工作台名称始终为 `${姓名}的工作台`。
- 保存后同步项目负责人、干系人中的本人名称。
- 数据仅本地存储。

验收标准：

- 改名后左上角立即变化。
- 头像缩写随姓名立即更新：中文取第一个字，英文取首字母（最多两个）。
- 设置中不存在“头像缩写”和“助手名称”字段。
- 不存在独立的工作区名称字段。
- 刷新后姓名、角色、头像保持。

## 7. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 本地优先 | 默认离线可用；SQLite 为唯一真相源 |
| 隐私 | 敏感项目可切本地模型；发送前显示将发送的字段 |
| 性能 | 首屏 < 1.5s；10,000 条任务下筛选 < 200ms |
| 可访问性 | 键盘可达；正文对比度 ≥ 4.5:1；焦点可见 |
| 可扩展 | 新增连接器不改核心表；新增字段不写死 UI |
| 可恢复 | AI 写操作可撤销；同步失败可重试 |
| 跨平台 | Windows / macOS 优先，Linux 次之 |

## 8. MVP 范围

### 8.1 v1 必须做

- 今日工作台、收件箱、项目组合、项目详情。
- 快速捕获 + AI 解析。
- 独立 AI 对话页 + 操作确认。
- 我的工作流（自然语言 → 规则）。
- 日报 / 周报事实层 + 叙述层。
- 工作方式画像。
- 数据与集成页 + 三组连接器。
- 个人资料编辑与工作台名称派生。
- 明暗主题。

### 8.2 v1 暂不做

- 多人协作与权限。
- 云端同步与团队空间。
- 完整 Jira / 禅道双向同步。
- 自动执行外部写操作（如自动改 Jira 状态）。
- 移动端原生 App。

## 9. 成功指标

| 指标 | 目标 |
| --- | --- |
| 每日打开率 | ≥ 70% 工作日 |
| 捕获到确认时长 | 中位数 < 60 秒 |
| 今日承诺兑现率 | 相对基线 +15% |
| 周报生成时长 | 从 60 分钟降到 < 10 分钟 |
| AI 操作确认率 | ≥ 60%（说明建议有效） |
| AI 操作撤销率 | < 10%（说明预览准确） |
