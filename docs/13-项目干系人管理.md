# 项目干系人管理

版本：0.1.9，2026-10-22。

## 使用

1. 打开“新建项目”或“编辑项目”，在“干系人”区域点击“添加干系人”。
2. 填写姓名和角色，可连续添加多人。姓名必填，姓名及角色各最多 80 字；角色留空时保存为“项目成员”。
3. 修改已有行的姓名和角色，或点击该行垃圾桶移除。
4. 点击“保存项目”，干系人名单和人数立即同步到项目概览，并保存在本机。
5. 项目概览的“干系人”标题右侧有管理按钮，可直接打开编辑窗口的干系人区域。

未填写姓名时保留当前窗口和其他输入，并显示对应行的错误。增删行会保留已经填写的项目字段及其他干系人。点击取消或关闭窗口不会保存草稿。

可移除全部干系人，保存后显示“尚未添加干系人”，重启后仍为空。已有项目的人员和角色会预先填入编辑窗口。

干系人记录保存姓名、角色及头像缩写，修改姓名后同步更新缩写。项目负责人、团队成员头像、风险、里程碑、项目表及文档保留各自记录；干系人不代替账号、通讯录或外部系统成员。

- 保存干系人时检查原项目字段、文档、风险及里程碑保持完整。
- 实际关闭重开测试程序并查询 SQLite，验证名单和空列表持久保存。
- 浏览器在 390px 和 1440px 宽度检查输入行、管理入口与长文本布局。
- 继续更新原有桌面快捷方式对应的程序，源码与发布包同步 GitHub。
