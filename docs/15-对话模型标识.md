# 对话模型标识

版本：0.1.11，2026-10-22。

- 删除对话右栏的“安全边界”整块内容，保留工作上下文和可执行操作。
- 对话页锁定根页面滚动，消息区和右栏各自滚动；输入区持续固定在底部。
- 每条回复下方单独显示模型名称，接口有返回模型标识时记录该名称，否则使用发送该请求时选中的模型。
- 保存新的模型后，顶部状态和输入区立即显示新配置，下一次提问使用新模型，回复下方显示对应名称。
- 模型切换不改写历史消息；请求进行中切换模型也不会把旧请求的回复标成新模型。
- 确认和取消操作生成的状态消息沿用原待确认回复的模型标识。
- 未配置供应商时使用“本地规则”；旧历史消息未记录模型时显示“来源未记录”，不使用当前模型补写历史。
- 长模型名称可换行，悬停可查看完整名称；消息的文字按普通文本显示。

回归覆盖模型切换、历史保留、请求中途切换、操作确认与取消、缺失模型名、关闭重开、窄屏与较矮窗口及其他页面滚动。

沿用已有桌面入口与本机工作数据，源码和发布包同步 HULIKU。
