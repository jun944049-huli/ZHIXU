# 50 MB 上传与模型对话

版本：0.1.8，2026-10-22。沿用现有桌面程序和数据目录。

## 上传与恢复

- 桌面版每文件最多 50 MiB（52,428,800 字节，界面标示 50 MB），一次最多 10 个，按顺序处理。
- 支持 DOC、DOCX、XLSX、PDF、PPTX、TXT、MD、CSV。旧版 XLS / PPT 需另存为新版格式；扫描 PDF 需先 OCR。
- 修复原来必须解析成功才保存原文件的流程：先保存到本机附件目录，再在独立线程解析。
- 原文件保存成功但解析失败时，会创建附件记录并显示解析原因；已选文件和分析参数保留，可重试失败项。
- 附件记录提供“重新解析原文件”和“导出原文件”，不需要重新选择源文件。原文件使用内容哈希核对。
- 解析时间上限 180 秒，解析线程内存上限 1 GiB，解压内容上限 256 MiB。不同文件的文本、页数与解压规模不同，50 MB 以内并不代表任意复杂文件均能解析成功。
- 正文单文件上限 100 万字，本机正文总量上限 1000 万字，数据库快照容量上限 64 MB。超出正文解析限制仍保留原文件，可拆分章节进行分析；不静默截断全文。
- AI 全文分析按 2 万字分段，可能产生多次供应商请求。失败时保留原文并说明原因，附件分析仍可回退本地规则。
- 浏览器预览仅支持较小文本附件；Office/PDF 与 50 MB 附件请用桌面版。

本次未取得用户报错的原文件，因此不能断言该文件的具体失败原因。已修复的共同问题包括原来 20 MB 文件限制、12 万字正文限制、8 MB 工作区快照限制，以及解析失败导致原文件不保存。

## 配置与问答

1. 打开左下角“个人资料与设置”，填写 API 地址和 API Key，选择获取到的文本模型。
2. 诊断供应商，确认真实文本请求通过，再点击“保存”。诊断与保存为两个操作。
3. 首页顶部显示当前供应商和模型，侧栏显示供应商，进入“对话”可查看当前模型。
4. 直接提问或下达自然语言指令，例如“解释关键路径”“星火项目明天交给小陈验收，预计 2 小时”“把星火整体进度调到六成”。
5. 普通知识问答直接展示模型回答；任务、项目、进度、风险和收件箱修改先生成草稿，点击“确认执行”后才写入。
6. 保存新模型后，下一条请求立即使用新模型；重启保留配置、历史和已确认记录。

修复发送消息时强制切回本地指令的问题。已配置模型后，问答和指令理解通过桌面后端真实调用所选供应商，复用已配置的 Chat Completions / Responses 协议。没有供应商时才使用本地任务规则。

模型请求失败显示 HTTP / 网络 / 返回结构等原因，保留原问题，提供“重试模型请求”。失败不会自动改为本地规则，也不会把普通问题写入收件箱。单次问题最多 2 万字，请求超时 90 秒，发送中阻止重复提交。

## 上下文与范围

请求包含近期最多 24 条消息、本地日期、项目候选及有限工作摘要。参考范围可选项目；摘要最多包含 150 条任务、100 个项目摘要、4 份相关附件的摘要和前 8000 字，以及产能、工作流和所选项目近期记录。不会自动发送全部文件或密钥，超过范围的数据不能视为模型已经读取。

模型动作经结构、参数、日期和项目 ID 校验，非法或不存在的项目操作被排除并提示；一次最多 10 项。新项目仅在用户明确请求后提出草稿，确认后创建。对话中的模型操作尚不支持任意任务编辑、删除或工具执行，不声称已执行未支持的操作。

目前没有联网搜索、后台自主执行和跨设备同步。当前模型能力取决于供应商及所选模型。本次接通针对 Windows 桌面版；浏览器预览提示使用更新后的桌面版。

## 验证

- 单元测试覆盖 50 MB 边界、原文件保留及重新解析、长文、数据库容量、模型协议、上下文、非法动作和无本地回退。
- 文档桌面回归上传约 49 MB 的有效 PDF，解析正文、导出逐字节校验，检查超 50 MB 后保留文件选择和错误原因。
- 模型桌面回归使用本机模拟供应商，通过真实 IPC / HTTP 校验首页同步、多轮问答、语义任务、进度、新项目、确认后写入、401 重试、模型切换与重启恢复。
- 所有回归使用独立临时配置，不向外部供应商发送真实个人数据。
- 更新沿用 `%LOCALAPPDATA%\Programs\Xiaoyu\Xiaoyu.exe` 和已有“小鱼测试版”快捷方式；源码与发布包同步 HULIKU。
