## 品牌

应用名称改为「知序」，表示把信息归整为有序的行动。保留用户自定义的助手昵称，原默认昵称「小鱼」升级为「知序」。

四款原创矢量图标位于 `prototype/brand/`，对比页位于 `design-review/品牌方案.html`：

- A「归序」：石墨色底、白色秩序线条与绿色落点。
- B「知页」：蓝色底、折页与信息条目，突出知识与文档。
- C「序环」：白底、开放环形与绿色落点，突出整理与持续推进，已选定。
- D「知行」：深绿色底、转折箭头，突出从想法走向行动。

用户已选定白底 C「序环」，应用、窗口及 Windows 程序统一使用该图标。执行 `npm run brand:render` 可从矢量源重新生成 PNG 与包含七种尺寸的 Windows ICO。桌面沿用原程序位置与数据目录，更新同一个快捷方式并更名为「知序」；GitHub 发布仍待整版界面确认。

## 页面与流程

- 常用入口优先：今天、对话、收件箱、项目；报告、回顾及连接设置放在其后。
- 对话默认聚焦消息与输入区，参考内容按需打开；删除静态能力说明和重复状态区，保留实际模型来源。
- 对话右上角新增「工作区」，侧栏包含文件、终端和浏览器，可收起或展开。聊天草稿在切换工具时保留。
- 文件区可浏览主动选择的本地文件夹及已上传附件，支持目录切换、文本/图片预览与系统打开。文件夹授权限当前应用会话；不自动读取未选择的目录或把文件发给模型。
- 浏览器采用独立的原生网页视图，支持地址、后退、前进及刷新；与工作台 IPC 隔离，打开工作台弹窗时隐藏网页，避免覆盖弹窗。
- 终端使用持久 PowerShell 进程，支持命令输出、目录/变量保留、历史及停止后重启。当前为命令终端，不提供交互式 TUI、密码输入或完整终端仿真；只执行用户明确输入的命令。
- 今天使用紧凑的工时条和任务分组，移除宣传式卡片与重复说明。
- 收件箱以原文、安排与确认操作为主，保留删除、恢复、附件及项目归属。
- 项目卡片与台账切换显示，同一批信息不再重复铺开；新增项目先填写名称、负责人和目标，进度及其他字段按需展开，干系人仍可直接编辑。
- 设置分为「通用」「模型」，保留未保存的输入。自定义模型优先填写 API 地址和密钥，高级协议及手动模型设置按需展开。
- 连接与数据分为「连接」「插件」「工作约定」「字段与备份」，移除未接入连接器的占位卡片。
- 报告移除重复说明侧栏，保留范围选择、编辑、保存和导出。
- 统一浅灰导航、白色内容、石墨色主操作及语义状态色，完善深色和窄屏布局。
- 第二轮恢复项目统计独立边框、待办及收件箱分区、项目详情、报告及数据工具的边界；浅灰画布配白色内容，放大标题和常用文字。补充 496 × 604 窄窗口检查。
