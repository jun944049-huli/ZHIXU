# 知序 0.2.10

完善桌面自动更新的网络连接，沿用原安装位置、快捷方式与工作数据。

- 更新检查与下载使用系统代理；运行环境已设置 `HTTPS_PROXY` 或 `HTTP_PROXY` 时，沿用该代理，避免版本能检查但安装包一直停在 0%。
- 连接或下载连续 60 秒没有响应时停止等待，说明超时原因，可重新检查更新；未完成的安装包不会进入安装状态。
- 后台下载仍通过 SHA-512 校验，完成后由用户点击“重启并更新”，安装前保存并备份数据库。

使用入口为左上工作台 → 设置 → 通用 → 软件更新。默认启动约 15 秒后检查，此后每 6 小时检查一次。更新源为 GitHub Releases（仓库公开），通常无需配置凭据；网络或镜像无法匿名访问时，可填写仅授予所需仓库 Contents 只读权限的 GitHub 令牌。

0.2.8 及更早版本需先覆盖安装一次。完整说明见 [操作手册](26-知序操作手册.md#14-软件更新)，自动更新功能说明见 [0.2.9 发布说明](29-0.2.9发布说明.md)。

114 项自动测试通过。真实更新引擎覆盖正常下载、校验失败、下载停滞及重试；所有测试使用隔离数据，不消耗个人模型额度。
