# 0.1.1 桌面测试版

## 已修复

- 项目新建、编辑入口由演示提示改为真实操作，并保存到本地数据库。
- 项目台账新增“操作”列，提供编辑与删除；详情页也可删除。
- 删除项目需要二次确认，取消不会改变数据。确认后关联任务保留为未归属，
  项目资料与记录归档，其他日期的任务、收件箱和等待事项同步解除关联。
- 删除最后一个项目后，项目组合及详情入口可显示空状态。
- 项目任务页合并实时任务与示例明细，包含低优先级及其他日期任务，
  不再因示例明细存在而隐藏新任务；完成状态同步展示。
- 新建项目可以通过名称匹配到对话和任务捕获；项目详情中的新建任务默认关联当前项目。
- 当天任务为空时更新项目进度不再访问不存在的第一条任务；允许设置 0%。
- 每条对话草稿的确认和取消按钮作用于该草稿，防止执行另一条待确认操作。
- 对话确认的收件箱草稿实际入库；任务确认保留原文并更新产能。
- 已删除项目的旧对话草稿不能继续写入关联任务。
- 项目统计和侧栏任务数量改为从实际数据计算。
- 修复 390px 小屏幕顶栏横向溢出。

## 验证方式

1. `npm test`：13 项数据库、供应商接口和业务回归测试。
2. `npm run build`：TypeScript 检查与生产构建。
3. `npm run test:desktop`：桌面任务捕获、完成、收件箱确认、项目增删改、
   取消删除、各主页面导航、保存队列、关闭保存、重启恢复和 SQLite 表查询。
4. 对 `release/win-unpacked/Xiaoyu.exe` 运行相同桌面回归。
5. `npm run test:web`：独立浏览器会话中的项目创建、删除、刷新持久化，
   桌面与 390px 手机宽度检查，测试图片保存在忽略的 `.desktop-test/`。

供应商测试使用本地模拟服务，不消耗真实 API 额度。
测试用户资料独立于日常工作数据库。

## 当前边界

前端已有 React 入口，页面仍通过兼容层运行。后端为 Electron 主进程，
负责 SQLite 和供应商请求，不依赖公网服务器；这不是云端多用户服务。
桌面数据保存在 `%APPDATA%\Xiaoyu\workbench.sqlite`。

完整模型对话、外部连接器、提醒、上传、真实周报/月报汇总及文档导出仍待开发。
带有“演示”提示的操作不代表已接通，详情页中保留的示例里程碑、
风险、文档和时间投入不代表自动采集的工作事实。
浏览器与桌面数据独立，不会自动同步。
