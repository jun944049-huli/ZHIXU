# 0.1.2 连接器配置与测试说明

发布日期：2026-10-22。

本文保留早期版本的配置说明；当前完整操作见 [知序操作手册](26-知序操作手册.md)。

在 Windows 桌面版中打开“连接与数据 → 连接”，点击连接器的“配置”。
输入配置后可以保存、测试连接，支持读取的连接器还可以“保存并同步”。
浏览器预览仅展示配置表单，需要在桌面版中保存凭据和发起连接。

## 支持范围

| 连接器 | 需要填写 | 当前能力 |
| --- | --- | --- |
| 飞书 | App ID、App Secret；读取消息时还需 Chat ID | 应用认证、验证消息读取权限、手动导入消息 |
| 钉钉 | App Key、App Secret | 应用认证测试；尚未接收聊天消息 |
| 企业微信 | Corp ID、应用 Secret | 应用认证测试；尚未接收聊天消息 |
| 邮件 IMAP | 主机、TLS 端口、邮箱、授权码或密码、文件夹 | 验证邮箱读取权限、手动导入最近邮件 |
| 日历 ICS | HTTP 或 HTTPS 日历订阅地址 | 验证日历内容、手动导入未来 30 天日程 |

其他标为“尚未接入”的连接器暂时不能建立连接。手动捕获入口仍可使用。
“应用认证通过”只说明应用凭据有效，不代表能够读取聊天记录。
连接器状态来自实际验证，不再沿用原型中预设的“已连接”状态。

## 配置要点

### 飞书

从自己的飞书开放平台应用取得 App ID 和 App Secret。
应用需要获准读取目标会话消息，机器人或应用需要能够访问目标会话。
填写目标 Chat ID 后测试，才能验证该会话的实际读取权限。
只填写应用凭据时可测试认证，但不能同步消息。
读取失败时请检查应用权限、版本发布和会话可见范围。
单次同步最多读取 50 条消息。

### 钉钉与企业微信

使用自己企业应用的凭据。当前只向供应商请求应用访问令牌，验证凭据。
企业微信如返回 IP 限制错误，还需要在应用管理后台检查可信 IP。
当前没有消息回调服务或聊天归档接入，因此这两个连接器没有消息同步按钮。

### IMAP

在邮件服务商后台开启 IMAP，使用其公布的服务器与 TLS 端口，通常为 993。
若服务商要求客户端授权码或应用密码，应填写该值。
默认文件夹为 INBOX，可改为邮箱实际存在的其他文件夹。
连接强制使用 TLS，以只读方式打开邮箱，不改变已读状态。
单次最多读取最近 20 封；大邮件仅导入标题，小邮件提取正文，不保存附件。

### ICS

使用日历应用提供的 ICS 订阅地址，不是普通日历网页地址。
地址必须返回有效 VCALENDAR 内容；网页登录页会被识别为失败。
支持未来 30 天内的日程、常见重复规则和排除日期，最多导入 50 条。
按秒或按分钟重复的日程暂不支持。
订阅地址可能包含私密令牌，应像密码一样保管。

## 数据与状态

凭据和私密订阅地址通过 Windows 系统安全存储加密后保存在本机 SQLite。
再次打开配置时，已保存的敏感字段保持空白；留空会保留原值。
修改配置后会清除旧的验证状态，需要重新测试。
日志只记录操作结果，不记录密码、令牌或私密地址。

导入内容先进入收件箱，保留来源原文，确认后才生成任务。
重复同步会检查收件箱及已确认归档，不会重复创建相同来源记录。
断开连接会删除配置，已经导入的记录保留。
当前需要手动同步，没有后台定时同步，也没有云端或跨设备同步。

## 验证范围

自动测试覆盖供应商认证响应、错误处理、IMAP 只读 MIME 解析、
ICS 重复日程和排除日期、重复导入与凭据加密。
桌面端使用真实本地 HTTP 日历服务验证连接、失败提示、导入、
重启恢复及断开连接；浏览器端验证表单和移动布局。

未提供真实企业或邮箱账号，因此未代替用户验证实际账号的权限和服务商网络连通性。
请在桌面版内填写自己的配置并测试，无需在聊天中提供密码。
