# 知序 0.2.14

修复公开下载用户无法检查更新、自动更新不生效的问题。

## 原因

仓库转为公开后，更新逻辑仍按“私有仓库”处理：

- 没有本机 GitHub 登录或保存令牌时，直接在检查前中止并提示私有仓库，根本不会发起请求。
- 更新地址带 `private: true`，且空令牌也会传给 electron-updater，使其选用私有仓库接口并携带空凭据，GitHub 返回 401。

因此其他人安装后检查更新只会看到失败提示，自动检查也在同一处失败。

## 变更

- 更新改为公开仓库匿名检查：无需登录或令牌即可发现新版本。
- 只有确实填写了令牌时才使用带凭据的访问方式，不再传递空令牌。
- 不再读取本机 Git 登录，普通安装无需安装 Git，也不会被其他 GitHub 登录状态影响。
- 网络受限或遇到 GitHub 访问频率限制时，仍可在“软件更新 → GitHub 令牌（可选）”填写只读令牌。
- 更新说明中的“私有仓库访问”改为“GitHub 令牌（可选）”；访问状态显示“使用公开仓库，无需登录”。
- 自动检查与后台下载保持不变：启动约 15 秒后检查，此后每 6 小时检查；下载完成后提示“重启并更新”，确认后保存工作并安装。

其他功能与 0.2.13 相同。

## 升级

受旧更新逻辑影响、无法检查更新的用户，需要从 Releases 下载本版完整安装包并覆盖安装一次。升级沿用原安装位置、桌面“知序”快捷方式和工作数据，不需卸载或清空数据。

安装修复版后，后续正式新版本可自动检查并后台下载，下载完成后点击“重启并更新”安装。自动更新不会在工作中强制重启。

更新源为 GitHub Releases（仓库公开），通常无需配置凭据。

## 验证

119 项自动测试通过，包含无凭据检查、启动后自动下载、关闭自动检查、校验失败与重试。正式打包程序通过桌面持久化与软件更新回归；真实公开发布源的匿名检查和完整安装包下载通过 SHA-512 校验。安装仍需确认重启，不会强制中断工作。
