# 知序 0.2.0

2026-10-24

## 启动与更新

旧便携程序每次启动都会解压完整应用，解压期间没有工作台窗口。本版提供 `Zhixu-0.2.0-Windows-Setup.exe`，安装后直接启动本地程序，连续三次隔离数据测试从启动到可操作页面分别为 2080、1756、1433 毫秒，具体速度取决于电脑和磁盘。

更新使用同一个“知序”快捷方式、`%LOCALAPPDATA%\Programs\Xiaoyu\Xiaoyu.exe` 及 `%APPDATA%\Xiaoyu\` 数据目录，不生成第二个桌面客户端。后续版本运行新安装包覆盖更新。首次运行安装包可能需要等待解压，日常启动不重复解压。

本机已使用本次安装包完成覆盖更新，安装资源与测试构建 SHA-256 一致；安装位置复测三次为 1856、1320、1412 毫秒。实际窗口已打开并核对原模型、工作台、侧栏和去重后的逾期清单，项目、任务、收件箱及个人设置与更新前备份一致。更新前程序、快捷方式和数据库保存在 `%LOCALAPPDATA%\ZhixuBackups\before-0.2.0-时间戳\`。

## 逾期事项

- 修复独立提醒清单与任务不同步，造成内容未更新、重复提醒或完成后仍显示的问题。
- 逾期列表、今天的数量和项目任务状态统一从真实任务及截止日期计算。
- 修改标题、清单或备注立即更新对应提醒；截止日期仍已过期时继续提醒。
- 修改截止日期重新判断逾期；将逾期任务改期且没有另填截止日期时，截止日期同步到新安排日。
- “安排到今日”移动同一条任务并将截止日期改为今日，不复制任务。
- 完成、改期或移除一项仅影响该项，其他逾期事项继续显示。
- 同名任务按任务 ID 和项目区分，旧提醒一次迁移；相对日期固定为绝对日期，重启不漂移。
- 拒绝不存在的日期，保存失败不会移动原任务。

## 本次合并的改版

应用统一更名“知序”，使用白底 C 图标；完善浅色、深色和窄屏布局及分区边界。输入区固定底部，消息显示实际回复模型，侧栏恢复今天、收件箱和项目数量。个人设置统一到上方工作台，颜色及自选头像保存后生效。

工作区提供选择文件夹、附件预览、原生浏览器和 PowerShell 命令终端。插件支持 npm、公开 GitHub 和本地目录安装，兼容 MCP 服务，提供配置、连接、工具手动调用及卸载。具体兼容范围见插件指南。

桌面及本机 Vite 预览支持 DOC / DOCX、XLSX、PDF、PPTX 等附件，单文件最大 50 MB；失败保留选择和具体原因，解析失败保留原文件。已有项目可分析归档并拆解任务，新项目先生成可修改草稿并等待确认。旧版 XLS / PPT 需先另存为 XLSX / PPTX；扫描件 OCR 尚未接入。

## 验证

本版通过构建、类型检查和 62 项单元测试，并完成以下自动化回归：

- 七个主页面、六个项目页签、六类报表，任务和项目增改删除、收件箱归档恢复、导出和数据库备份。
- 逾期清单编辑、改期、安排到今日、同名项目隔离、逐项完成及重启保存。
- DOCX / XLSX / PDF / PPTX 上传、49 MB PDF、超限拒绝、失败保留、原文导出与重启恢复。
- 供应商模型获取、协议诊断、错误原因、问答与指令、模型切换、历史模型标识及凭据加密。
- 干系人、头像上传与颜色、通知角标、深色模式及桌面和窄屏布局。
- 文件夹和附件、终端、浏览器历史与弹窗遮挡、插件真实安装、MCP 调用、重启和卸载。
- 桌面启动、正常退出、重开及 SQLite 持久化。

测试使用临时工作台及本机模拟供应商，不修改个人任务，也不向真实通信服务发送测试消息。未接入的功能包括云端账号与跨设备同步、后台自动同步、系统通知、扫描件 OCR 和模型自动执行工具；界面不将这些功能显示为已连接。
