# 知序 0.2.4

2026-10-24

项目事项以自然语言录入、解析和确认，入口与操作保持一致。

- 项目详情顶部与任务列表的新增入口均改为“添加事项”，与实际打开的弹窗一致。
- 使用当前配置的模型将大白话整理为简短、可执行的任务标题，不再套用固定任务或擅自写入人名。原始描述与项目归属继续保留，标题可手动修改。
- 未配置模型时使用本地整理，去除口头铺垫；不再按固定长度直接截断任务或丢弃后续相关工作。过长内容会提示缩短或连接模型。
- “取消”“重新解析”“确认保存”位于弹窗底部同一排；确认按钮不再混在解析结果内部。窄窗口保持按钮完整可见。
- 模型解析显示实际使用的模型；失败显示原因并保留原文及上次结果。解析期间禁用保存，原文已修改时拒绝保存旧结果，需重新解析。

验证通过：构建与类型检查、78 项单元测试、桌面主流程回归，以及打包后的事项录入专项测试。专项覆盖本地与模型解析、项目入口名称、桌面及 496 × 604 窄窗口按钮对齐、失败保留原文及结果、密钥隐藏、请求期间修改原文校验、保存与重启恢复。模型请求通过真实 IPC 和本地模拟供应商 HTTP 验证。

沿用原“知序”桌面程序、快捷方式与本机数据。
