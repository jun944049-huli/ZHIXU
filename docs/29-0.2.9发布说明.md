# 知序 0.2.9

桌面版加入自动更新，后续版本可在原程序中完成下载与安装。

## 使用

点击左上工作台，进入“设置 → 通用 → 软件更新”。默认启动后约 15 秒检查，此后每 6 小时检查一次。新版本后台下载并校验，完成后点击“重启并更新”；安装前先保存工作并自动备份数据库，沿用原安装位置、桌面快捷方式与附件目录。

可以关闭自动检查，按需手动检查。网络、仓库权限、更新文件不完整、校验失败、空间或权限问题会显示对应说明，失败后当前版本仍可使用。

## 私有仓库

更新源为 `jun944049-huli/HULIKU`。优先读取本机 Git 已有的 GitHub 登录；没有已有登录的电脑可在软件更新中填写仅授权此仓库 **Contents: Read-only** 权限的 GitHub 令牌。凭据通过系统安全存储加密，不包含在安装包、网页页面或工作数据导出中。

模型 API Key 和网页访问密码不能替代 GitHub 凭据。0.2.8 及以前需先覆盖安装本版一次，之后才能在应用内更新。

## 数据与网页访问

更新安装前保存失败、存在未处理编辑、模型或文件请求、计时或多设备同步提示时，先保留工作并处理提示，再重试安装。自动数据库备份保存在工作数据目录下 `backups`，原附件保持原位置。更新期间网页访问会断开，重新启动后可再次开启。

具体步骤与权限配置见 [操作手册](26-知序操作手册.md#14-软件更新)。

## 验证

110 项自动测试通过，覆盖原有工作流、凭据存储、版本检查、后台下载、校验失败、重试及保存失败时阻止安装。正式打包版通过桌面回归与软件更新界面检查；真实更新引擎分别验证正常下载和错误校验值，损坏文件不会进入安装状态。测试使用隔离数据，不调用个人模型额度。

首次从旧版覆盖安装仍沿用原安装路径及工作数据。自动更新执行整套覆盖安装的最终验收，需要后续正式新版本发布后进行；不为测试强制改写日常版本号或运行未发布的更新。
