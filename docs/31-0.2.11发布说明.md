# 知序 0.2.11

补齐逾期、等待事项和附件记录的清单操作。

- **逾期事项**：点“安排到今日”或通过“改期 / 编辑”保存后，逾期清单保留并刷新，只移除已处理的那条，可以连续处理剩余事项；全部处理完弹窗自动关闭。已安排的任务仍会立即出现在今天待办中。
- **等待事项**：每条右侧新增“删除”，确认后删除并归档，不再出现在等待跟进和本地简报中；删除后清单保持打开，可继续管理。
- **附件记录**：每条右侧新增“删除”，确认后移除记录并归档。已生成的任务、项目和进展记录保留，原文件仍保存在本机附件目录。
- 清单按钮尺寸统一，窄窗口下自动换行且不产生横向溢出。

升级沿用原安装位置、桌面“知序”快捷方式和工作数据；已安装 0.2.9 及更高版本可在“设置 → 通用 → 软件更新”中更新。
