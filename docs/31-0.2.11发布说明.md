# 知序 0.2.11

补齐逾期、等待事项和附件记录的清单操作，减少重复整理。

- **逾期事项**：点“安排到今日”或通过“改期 / 编辑”保存后，逾期清单保留并刷新，只移除已处理的那条，可以连续处理剩下的逾期事项；全部处理完弹窗自动关闭。已安排的任务仍会立即出现在今天的待办中。
- **等待事项**：每条右侧新增“删除”按钮，确认后删除并保留在本机归档，不再出现在等待跟进和本地简报中；删除后清单保持打开，可继续管理。
- **附件记录**：每条右侧新增“删除”按钮，确认后移除附件记录并归档。已生成的任务、项目和进展记录都保留，原文件仍保存在本机附件目录。
- 清单按钮统一为同一尺寸，窄窗口下自动换行且不产生横向溢出。
