# 0.1.5 归档与回收站清空

- “归档与回收站”窗口右上角增加带垃圾桶图标的“清空”按钮，空列表时禁用。
- 点击后显示条数和范围，包括已删除、已忽略和已转为任务的归档原文。取消不改变数据。
- 确认清空后，这些记录无法从此窗口恢复；待处理收件箱、已创建的任务和任务自身的来源记录保留。
- 仅清除打开确认窗口时的记录，确认期间新增的归档保留，重复确认不会误删新记录。
- 外部记录仅保留连接器及来源 ID 作为去重凭据，不保留已清空归档的标题和原文；后续同步不会重新导入同一来源。
- 结果保存到本机，重新打开程序仍保持；已有备份不会被清空按钮修改。
- 本机继续覆盖固定程序位置，桌面仍使用唯一的“小鱼测试版”快捷方式；工作数据库及设置沿用。

验证覆盖未确认、取消、确认、空列表、重复确认、确认期间新增归档、来源去重和保存重载。
界面测试使用独立测试资料，不清空日常工作资料。浏览器截图检查 390px 和 1440px 的标题、清空和关闭按钮布局。
