# 知序异地访问说明

更新日期：2026-10-25。适用于“设备不在同一个 Wi-Fi / 局域网”的访问需求。

## 1. 浏览器直接打开知序

0.2.8 新增桌面主机提供的网页访问。手机、平板和其他电脑可以通过 HTTPS 地址登录，使用原电脑上的同一份项目、任务、对话和附件。无需处于同一个 Wi-Fi，也不需要给手机安装 Windows 程序。

数据仍保存在原电脑，没有迁移到独立云数据库。原电脑必须开机、联网、保持知序运行且不休眠。

## 2. 在原电脑开启

1. 更新并打开知序，点击侧栏上方的个人工作台，进入个人设置。
2. 在“常规”中点击“网页访问”。
3. 首次填写至少 12 个字符的访问密码，也可以点击“生成密码”后复制保存。密码只由本人保管，不提交到 GitHub。
4. 点击“开启网页访问”。首次会从 Cloudflare 官方 GitHub 下载并校验连接组件，需等待下载和连接完成。
5. 状态显示开启成功后，点击“复制地址”。使用完整的 `https://…trycloudflare.com` 地址。
6. 在手机或其他电脑的浏览器打开地址，输入访问密码登录。

后续开启时，密码留空可沿用已保存密码。知序不会在重启后自动开放网页访问，需要手动开启。

## 3. 可用功能与模块联动

| 模块 | 网页操作 | 数据关联 |
| --- | --- | --- |
| 今天、收件箱 | 新增、解析、编辑、完成、改期、归档及删除 | 与主机任务、逾期及侧栏数量同步 |
| 对话 | 使用主机已配置模型问答、更新状态、追加进展备注 | 使用同一份项目和任务上下文 |
| 项目 | 项目、任务、里程碑、风险、干系人和进展记录 | 沿用桌面端联动规则 |
| 文档 | 上传 DOC / DOCX / XLSX / PDF / PPTX / TXT / MD / CSV，每份最多 50 MB；分析、修改及下载原件 | 正文入同一数据库，原件保存在主机附件目录 |
| 报告、回顾 | 查看记录、生成及编辑报告、下载导出文件 | 使用主机实际工作记录 |
| 个人设置、连接与数据 | 工作台配置、供应商设置、已有连接器操作及备份下载 | 主机保存的密钥以占位符显示，实际调用由主机完成 |
| 工作区 | 查看已上传附件、上传新文件 | 不会访问手机的任意本地目录 |
| 终端、插件、本机文件夹、内嵌浏览器 | 在桌面端使用 | 不通过公网提供主机命令执行或任意文件访问 |

这是同一个个人工作台的多设备入口，不是多人权限系统。知道密码并登录的设备可以查看和修改工作记录，只向自己的设备或可信使用者提供地址和密码。

## 4. 多设备同步和保存冲突

在线页面约每 5 秒检查一次变更。页面空闲且没有未保存编辑时自动载入最新记录；正在输入、编辑弹窗或处理任务时保留当前内容并提示更新。

如果两台设备同时修改，先保存的版本生效。另一台设备会收到“其他设备已更新”的提示，本次旧数据不会覆盖新数据：

1. 点击“导出本次编辑”，保留当前工作数据及尚未提交的表单文字。
2. 点击“重新载入”，确认后加载最新版本。
3. 对照导出内容补回本次修改，再保存。导出的 JSON 供核对，不是自动合并导入文件。

网页访问需要网络，不提供离线编辑后自动合并。上传或模型请求失败时，按页面原因处理后重试。

## 5. 地址、密码和关闭访问

- 当前采用 Cloudflare Quick Tunnel 临时地址，无需购买域名或配置路由器端口转发；地址可能在每次重新开启后改变。
- 关闭知序、电脑休眠、断网或点击“关闭访问”后，网页将无法继续访问。
- 修改访问密码会关闭当前入口并退出全部已登录设备，需要重新开启并登录。
- 浏览器会话最长 12 小时，可点击顶部退出按钮提前退出。
- 访问密码以加盐哈希保存；主机现有供应商密钥不随工作数据明文下发网页。

Quick Tunnel 是临时访问方案，官方不承诺可用性，不适合作为长期生产服务。需要固定网址、长期稳定运行或不依赖原电脑时，后续应部署正式服务或固定 Cloudflare Tunnel，并配置自己的域名及访问策略。

官方说明：[Cloudflare Quick Tunnels](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/)。

## 6. 排查与验收

| 情况 | 处理 |
| --- | --- |
| 首次组件下载失败 | 检查原电脑能否访问 GitHub；保持联网后重新开启，组件经校验成功后可复用 |
| 外网连接超时 | 检查原电脑网络是否允许 Cloudflare 连接；换网络后重试 |
| 手机打不开地址 | 核对完整 HTTPS 地址、知序运行状态、电脑休眠情况，以及地址是否已被重新开启替换；新地址首次解析可能稍有延迟，可稍后刷新 |
| 登录失败 | 核对网页访问密码；连续错误后需等待限制时间，或在主机重设密码并重新开启 |
| 提示数据已更新 | 按上一节保留本次编辑、载入最新记录再合并 |
| 原电脑没有网页访问按钮 | 检查实际运行的安装版是否已更新至 0.2.8；旧浏览器开发预览不具备此入口 |
| 文件失败 | 检查扩展名和单文件 50 MB 上限；扫描 PDF 暂无 OCR；旧 XLS / PPT 需转换为 XLSX / PPTX |

实际使用前，在手机关闭 Wi-Fi，改用移动网络打开地址，登录后查看一个原有项目；追加明确标注为测试的备注，在原电脑核对同步，再清理测试内容。自动化测试不能替代用户手机的真实移动网络验收。

`127.0.0.1:5173` 等开发预览和 GitHub Releases 下载页不是异地工作台地址。不要直接开放开发端口，或把私人数据库、密码、API Key 放到 GitHub。
