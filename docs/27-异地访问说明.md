# 知序异地访问说明

更新日期：2026-10-24。适用于“设备不在同一个 Wi-Fi / 局域网”的访问需求。

## 当前状态

**知序还没有已部署的公网 Web 工作台。本次文档发布没有开通公共访问地址。**

正式功能通过 Windows 桌面程序运行，数据库、原附件、插件和终端都在原电脑。浏览器开发预览是另一套本地数据；仅把预览地址暴露出去，不会变成可共享桌面资料的完整工作台。

| 方式 | 不同 Wi-Fi 能否使用 | 是否操作原桌面数据 | 当前情况 |
| --- | --- | --- | --- |
| `127.0.0.1:5173` 等本地地址 | 不能直接使用 | 否，开发预览有独立数据 | 本机预览 |
| `电脑局域网 IP:8765` | 通常不能 | 否，旧静态原型 | 不作为异地方案 |
| 经身份验证的远程桌面 | 可以，需双方联网且原电脑开机 | 是，使用原来的知序 | 可配置，需用户完成远程服务登录和设备授权 |
| 知序的公网 HTTPS 工作台 | 完成部署后才可以 | 需实现统一后端与数据存储 | 尚未实现和部署 |
| GitHub 仓库 / Releases | 可以下载源码或安装包 | 不会传输工作数据 | 已发布，但不是在线运行地址 |

## 方案一：远程使用原来的桌面版

适合先从异地使用完整功能、保留现有真实项目和附件的需求。无需为知序另建数据库、购买域名或改造网页端，但原电脑必须开机、联网并允许远程连接。

可选择 Chrome 远程桌面等支持互联网连接和身份验证的远程工具。以下是 Chrome 远程桌面的设置流程；最终以 Google 官方页面显示为准：

1. 在安装知序的电脑打开 [Chrome 远程桌面](https://remotedesktop.google.com/access)。
2. 使用自己的 Google 账号登录，按“设置远程访问”的指引安装主机组件。
3. 设置这台电脑的名称和连接 PIN，完成系统显示的安装及授权步骤。账号密码、验证信息和 PIN 由自己输入，不提交到知序或 GitHub。
4. 保持电脑联网和可远程访问，确认不会在需要使用时自动进入睡眠。
5. 在另一台电脑的浏览器打开相同入口并登录获授权账号，选择已配置电脑，按页面提示连接。
6. 连接后打开原“知序”快捷方式。看到的就是原电脑上的项目、任务和附件，实际操作发生在原电脑上。

这属于远程控制电脑，不是为知序开通独立网址或多用户账号；对端也可能看到原电脑上的其他窗口。请只授权自己的设备与可信账号，不转发凭据。服务是否可用还取决于两端访问 Google 服务的网络条件。

官方帮助：[通过 Chrome 远程桌面访问其他计算机](https://support.google.com/chrome/answer/1649523?hl=zh-Hans)。

### 验收：必须换网络测试

1. 原电脑保持在线，正常打开知序。
2. 另一台设备切换到手机热点或其他网络，关闭原 Wi-Fi。
3. 从远程入口连接，确认身份验证正常，并能打开原有实际项目。
4. 新增一条明确标注为测试的备注，在原电脑核对出现；验证通过后按需处理该备注。
5. 断开后重新连接，确认仍能访问同一份数据。

**完成上述跨网络验证后，才算异地连接已开通。** 当前尚未替用户完成账号登录、主机授权和这项验证。

## 方案二：通过知序网址直接访问

如果目标是“手机浏览器输入网址，直接使用知序”，则需进行 Web 服务建设和部署。它与远程桌面是不同需求，需要确定设备、访问人数、数据存放位置及是否保留终端等本机能力。

实施范围包括：

1. 提供浏览器可调用的正式服务，将目前仅供桌面使用的模型、数据库、附件等接口改造成经过认证的 Web 接口。
2. 设置个人登录、会话、权限、HTTPS 和上传限制。终端、插件及本地文件能力不能无认证公开。
3. 确定电脑常驻服务还是服务器托管；确定已有桌面数据迁移、备份和后续同步规则，避免生成两套互不一致的项目。
4. 部署后使用外部网络验证登录、50 MB 文档上传、分析、任务更新、重新登录后的数据一致性与访问撤销。

域名只负责地址名称，买了域名也不会自动产生后端。现有旧原型地址或文档中提到的目标域名，不代表已经解析、部署或可访问。

当前开发预览的附件接口仅允许本机访问。不能通过关闭这项校验、直接开放开发端口或路由器端口转发来代替正式部署。

## 如何选择

- 想尽快异地使用**现有完整桌面功能与原数据**：选择方案一，完成远程服务的个人登录、设备授权及跨网络验证。
- 想要**知序自己的网址、手机网页和后续多设备使用**：选择方案二，先确定部署与数据方案，再实施和验收。

在方案和授权未确定前，不开放电脑端口、不上传现有私人数据库，也不把 API Key 放进公共地址。
