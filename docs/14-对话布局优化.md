# 对话布局优化

版本：0.1.10，2026-10-22。本版同时包含项目干系人的添加、修改、移除与持久保存。

## 调整

- 移除对话区使用多组固定高度和最小高度的布局，改为占满顶部导航下的可用窗口高度。
- 去掉对话页底部大块留白，输入区保持在窗口底部，保留附件、参考范围、润色、模型及发送操作。
- 消息记录在输入区上方独立滚动，长回复或多轮对话不会把输入框推走。
- 右侧工作上下文独立滚动，不再把整个页面撑长；窄屏继续隐藏该侧栏。
- 切换项目、今日、报表等其他页面后恢复普通页面滚动。
- 输入区不覆盖消息，原有 Enter 发送和 Shift+Enter 换行行为保留。

使用弹性布局固定输入区，不依赖屏幕绝对坐标。窗口缩放或高度改变时重新分配消息区高度，输入区保持可见。

## 验证

- 浏览器检查桌面、窄屏、横屏和较矮窗口的输入区位置、正文滚动及页面溢出。
- 长对话滚动前后输入区位置保持稳定，消息末尾可见，右侧栏可单独滚动。
- 真实桌面模型对话回归检查消息发送、输入区固定、失败重试和模型切换。
- 同时回归干系人增删改、取消、关闭重开及本机 SQLite 保存。
- 新版本继续覆盖原桌面程序，源码和发布包同步 HULIKU。
