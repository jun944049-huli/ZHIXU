# 知序 0.2.8

手机或其他电脑可以通过浏览器登录原电脑上的知序，查看并操作同一份工作数据。

## 使用

点击桌面左上工作台，在“设置 → 通用 → 网页访问”设置访问密码并开启，复制生成的 HTTPS 地址，在其他设备浏览器登录。无需购买域名，无需处于同一 Wi-Fi。首次下载并校验官方连接组件需要等待网络连接完成。

主机须保持知序运行、联网且不休眠。当前使用 Cloudflare Quick Tunnel 临时入口，重新开启地址可能变化，不承诺长期稳定性。固定网址及不依赖个人电脑的托管服务需另行部署。

## 变化

- 网页复用桌面的 SQLite、附件解析、模型对话、任务和项目联动能力。
- 登录使用访问密码、加盐哈希及有期限的 HttpOnly 会话；主机保存的模型密钥以占位符呈现，调用由主机完成。
- 文档单文件上限 50 MB；支持 Word、Excel、PDF、PowerPoint 等已有格式，可下载原件和报告。
- 在线客户端定期检查更新；同一时间修改会提示保存冲突，提供导出当前编辑及重新载入，避免旧页面覆盖新记录。
- 正式页面将分散脚本合并加载，减少外网打开和同步刷新时的网络往返；单纯读取已有记录不会触发多余保存。
- 创建任务时统一截止日期与逾期状态，避免其他设备首次打开新任务时补写字段、误触发保存冲突。
- 访问入口可关闭、修改密码并撤销会话；终端、插件和任意本机目录能力保留在桌面。
- 操作手册同步补充浏览器使用路径、模块联动及故障处理。

## 验证

98 项自动测试通过。测试使用独立示例数据库和本机模拟模型接口，不调用个人模型额度。已通过真实公网 HTTPS 登录、电脑与手机尺寸浏览器共享更新、模型问答、DOCX 上传及原件下载、7 个手机主页面、保存冲突及退出测试。50 MB 边界、会话撤销、同源校验、密钥保护和读取不触发保存等另有自动化覆盖。

测试没有代替用户在真实手机上关闭 Wi-Fi 后的移动网络验收，也没有替用户设置日常工作台访问密码。

更新沿用原“知序”安装位置、桌面快捷方式及工作数据目录。安装前正常关闭应用；完整备份需同时保留数据库与原附件目录。
