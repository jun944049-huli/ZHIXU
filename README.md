# 知序

> 以 AI 为核心的个人工作平台，连接知识、项目与工具。

知序把 AI 对话、文档分析、任务推进和项目管理放在同一个工作台。你可以接入自己的模型，结合项目上下文问答、梳理资料和拆解工作；也可以使用文件、浏览器、终端和插件，把分散的信息与流程连接起来。

工作数据保存在本机，模型密钥使用 Windows 安全存储加密。

## 主要功能

### 对话与模型

- 接入 OpenAI 兼容接口、DeepSeek 或自定义供应商，使用当前选定的模型真实问答。
- 对话可结合有限的项目、任务和附件上下文；生成任务、项目、风险等草稿，确认后才写入。
- 长对话自动整理交接摘要并保存在本机，同时保留完整原文，可分批查看更早消息。
- 明确的工作进展可同步到对应任务和项目，保留原话、记录人和时间。

### 项目与任务

- 项目台账、独立颜色、干系人、里程碑与风险；删除项目时保留任务并解除关联。
- 任务捕获、改期、截止日期、优先级、计时、完成状态和进展备注。
- 逾期与等待清单；安排或改期后保留清单，连续处理剩余事项。
- 收件箱确认、拆分、归档、回收站恢复与批量清理。
- 侧栏实时统计今天待办、收件箱和项目数量，窄窗口保留角标。

### 文档与报告

- 批量上传 DOC、DOCX、XLSX、PDF、PPTX、TXT、Markdown、CSV，单文件上限 50 MB。
- 先保存原文件，再提取正文；支持本地规则或已配置的模型分析。
- 分析结果可归档到已有项目、拆解为任务；新项目保留为可修改草稿，确认后创建。
- 日报、周报、月报、项目状态与风险清单，可编辑、保存快照并导出 Markdown、Word、Excel、PDF。

### 工作区与扩展

- 文件浏览、原生网页视图和 PowerShell 命令终端。
- 插件支持 npm 包、公开 GitHub 仓库和本地目录，可连接 MCP 服务并调用工具。
- 飞书、钉钉、企业微信、IMAP、ICS 可保存配置并测试连接；飞书消息、IMAP 邮件与 ICS 日程可手动导入收件箱。

### 数据与访问

- 本机 SQLite 存储，附件单独保存；API Key、连接器凭据和插件环境变量加密保存。
- 可选 HTTPS 网页访问：手机或其他电脑通过浏览器登录，使用主机上的同一份数据。
- 自动检查更新、后台下载并在重启后安装，沿用原安装位置和工作数据。
- 支持工作数据导出、数据库备份及完整数据目录迁移。

## 下载与安装

前往 [GitHub Releases](https://github.com/jun944049-huli/ZHIXU/releases/latest) 下载 `Zhixu-0.2.14-Windows-Setup.exe`，安装后从桌面“知序”快捷方式打开。无需安装 Node.js 或 Python。

升级沿用原安装位置、快捷方式和 `%APPDATA%\Xiaoyu\` 工作数据。旧版无法检查更新时，先下载完整安装包覆盖安装一次。0.2.14 起无需 GitHub 登录即可自动检查并下载更新，下载完成后点击“重启并更新”安装。

## 开发

需要 Node.js 24。

```powershell
npm install
npm run dev        # 桌面开发模式
npm run build      # 类型检查与生产构建
npm test           # 自动化测试
npm run dist       # 生成 Windows 安装包
```

浏览器预览：

```powershell
npm run dev:web
```

目录结构：

```text
src/main/       Electron 主进程、数据库、模型与系统能力
src/renderer/   React 渲染入口
src/shared/     主进程与界面共享的契约
prototype/      工作台页面与样式
tests/          单元测试与桌面/浏览器回归
docs/           使用手册与版本说明
```

## 数据与隐私

- 工作数据、附件、聊天记录和配置保存在本机 `%APPDATA%\Xiaoyu\`，不使用自有云端后端。
- 模型请求发送给当前选定的供应商；供应商地址、密钥和模型由使用者自行配置。
- 网页访问使用密码、加盐哈希和有期限的会话；主机密钥不会以明文下发给浏览器。
- 仓库不包含用户数据库、附件、密钥或安装包。测试使用隔离数据和本机模拟服务。
- 完整迁移时请正常退出程序，再备份整个 `%APPDATA%\Xiaoyu\`；单独备份 SQLite 不包含原附件。
