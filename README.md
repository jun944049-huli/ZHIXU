# 知序

> 以 AI 为核心的个人工作平台，连接知识、项目与工具。

知序将 AI 对话、文档分析、任务推进与项目管理融入同一个工作空间。从理解资料、梳理思路，到拆解任务、跟进项目和输出成果，让思考与行动保持连贯。

你可以接入自己的模型，结合项目上下文进行问答与分析；也可以在工作区使用文件、浏览器、终端和插件，将分散的信息、工具与工作流程连接起来。

## 当前状态

当前版本为 **0.2.4「知序」**。项目中的新增入口统一为“添加事项”。口语化描述由当前所选模型提炼为简短任务标题，原文保留供追溯；未配置模型时使用本地整理。“重新解析”和“确认保存”统一放在弹窗底部同一排，结果可继续修改。

发布说明见 [0.2.4 更新](docs/22-0.2.4发布说明.md)，上一版见 [0.2.3 更新](docs/21-0.2.3发布说明.md)，改版记录见 [知序改版预览](docs/16-知序改版预览.md)，图标对比见 [品牌方案](design-review/品牌方案.html)。

已接通真实存储的功能：

- 项目新建、编辑、删除；项目台账包含“操作”列。
- 新建和编辑项目可添加、修改与移除干系人，填写姓名及角色；项目概览提供管理入口，保存后显示并持久保留。
- 对话页占满窗口可用高度，输入区固定在底部；参考内容按需打开，切换其他页面恢复正常页面滚动。
- 对话右栏已移除“安全边界”区块；每条新回复下方记录实际模型名，切换模型后保留历史回复原来源。
- 对话可打开工作区侧栏：浏览本地选择的文件夹、查看已上传附件、预览文本及图片，并使用系统应用打开其他格式。
- 工作区浏览器支持网页地址、前进后退及刷新，采用独立原生网页视图，工作台弹窗打开时不会被网页覆盖。
- PowerShell 命令终端支持输出、历史、目录和变量保留、停止及重启；文件夹选择限当前应用会话。此版本不提供交互式 TUI 或完整终端仿真。
- 删除项目保留任务并解除关联，项目记录归档，重启后不会重新出现。
- 任务捕获、编辑、改期、删除、状态切换、计时、筛选与工作时间调整。
- 逾期提醒从真实任务统一计算：更新清单即时同步，修改截止或改期后重新判断，逐项完成互不影响；旧提醒迁移一次，不再重复出现。
- 收件箱确认、删除与回收站恢复、忽略、拆分、批量归档及原文保留；归档与回收站支持确认后清空。
- 侧栏显示今天全部未完成任务、收件箱待处理及项目数量，窄窗口保留数字角标，处理后立即更新；超过 99 显示 99+，悬停可见完整数量。
- 项目任务页展示当天、其他日期和已完成任务。
- 日报、周报、月报、项目状态、风险与需求清单根据本地记录汇总。
- 报表人工编辑、快照保存、复制及 Markdown / Word / Excel / PDF 文件导出。
- 项目风险、里程碑、等待事项与个人实验可增改移除，看板状态与任务同步。
- 对话和项目文档支持批量上传 DOC / DOCX / XLSX / PDF / PPTX / TXT / Markdown / CSV，单文件上限 50 MB；先保存原文件，再提取正文。
- 附件支持本地规则或已配置的 AI 分析，已有项目自动归档并拆解任务；新项目保留为可修改草稿，明确确认后才创建。
- 可修改项目归属、分析指令、摘要、任务标题、负责人、日期、优先级及工时，支持原文件导出与重新分析。
- 分析后在对话页显示简短摘要和任务概览，“详细”自动定位关联项目并打开附件任务清单；保存后关闭编辑窗口，返回对话页。
- AI 按交付物或阶段归并相关工作，详细步骤存入“详细”字段；可勾选相关任务并填写新标题合并。不同负责人、日期或里程碑的已有任务分别保留，合并不改变原完成比例，完成整项后同步关联状态。
- 上传失败保留已选文件、项目及指令，逐个显示原因并重试失败文件；已成功附件不重复导入。
- 正文解析失败仍保存附件记录，支持重新解析和导出原文件；单文件正文最多 100 万字，原文件大小与正文规模分别检查。
- 文本附件支持 UTF-8、带 BOM 的 UTF-16 及常用 GB18030 中文编码。
- 自定义任务、项目与风险字段可配置、填写及停用；支持单选候选项。
- 个人画像展示实际任务完成比例与计时记录，数据页可导出工作数据和备份 SQLite。
- 保存供应商配置后，顶部和对话立即同步当前模型，重启后保留。
- 已配置模型时，问答和自然语言指令真实调用所选模型，支持近期对话及有限工作摘要；接口失败显示具体原因并可重试，不自动改用本地规则。
- 模型可以生成任务、进度、风险、收件箱和新项目草稿，明确确认后才写入；明确陈述已有工作完成、进行中或阻塞时按真实任务 ID 同步状态，有歧义或假设时保留待确认清单。未配置模型时仍可使用本地任务规则。
- 里程碑可关联项目内任务，关联任务全部完成后自动完成节点；项目按任务完成比例计算进度，有未完成里程碑时不会误记为 100%。修改、撤销完成与删除任务均更新关联状态。
- 个人设置、对话记录、主题与自定义快捷指令保存在本机。
- 工作台头像与个人设置一致，支持 JPG / PNG / WebP 上传（最大 5 MB）、居中裁切及移除，保存后重启保留；底部重复个人入口已移除。
- `npm run dev:web` 的本机浏览器预览也可上传 Office / PDF，沿用桌面解析器和单文件 50 MB 限制；原附件保存在 `%LOCALAPPDATA%\ZhixuWeb\attachments`，不占浏览器正文存储配额。静态 HTML 预览不提供附件服务。
- 配置供应商后可调用真实 AI 润色；桌面版 API Key 使用系统安全存储加密。
- 自定义供应商填入 API 地址与密钥后自动获取模型；支持列表选择及手填模型，兼容 Chat Completions / Responses。
- 供应商诊断检查配置、模型列表及真实文本请求，显示接口路径、耗时、HTTP 状态、上游错误及处理建议。
- 飞书、钉钉、企业微信、IMAP、ICS 可保存配置并测试连接；凭据加密保存在本机。
- 飞书消息、IMAP 邮件、ICS 日程可手动导入收件箱，重复同步自动去重。
- 插件独立管理：支持 npm 包名、公开 GitHub 仓库及本地目录，提供官方源与大陆镜像；失败保留输入并说明原因。
- 插件通过兼容性检查后可设置启动参数与加密环境变量，连接 MCP 服务、查看工具、手动调用、停用或卸载。安装不会执行包的生命周期脚本；暂不支持其他宿主专用插件、Python 服务或需现场编译的项目。详见 [插件指南](docs/17-插件安装与管理.md)。
- 钉钉与企业微信目前支持应用认证测试，消息接收尚未接入，界面明确显示范围。

尚未完成：模型联网搜索与工具执行、其他外部连接器、自动后台同步、系统通知、
扫描件 OCR、旧版 XLS / PPT 解析、云端账号与跨设备同步。工作流目前保存规则草稿，不会自动执行。
本地简报需在程序中打开，不提供定时推送。人员、关联扩展字段目前保存为文本。

测试默认使用本机 Microsoft Edge 的独立临时会话，不读取个人浏览器数据。
Windows 桌面测试覆盖真实窗口操作、关闭重开及 SQLite 表查询。
连接器测试还覆盖本地 HTTP ICS 请求、导入去重、配置重启恢复和凭据加密。
逐页回归覆盖 7 个主页面、6 个项目页签、6 类报表，以及真实文件导出与数据库备份。

附件专项回归使用真实 DOCX、XLSX、PDF、PPTX 文件，检查自动归档、草稿确认、修改、去重和原文件重启导出。
供应商专项回归使用本机模拟服务检查模型自动获取、协议识别、错误原因、密钥加密和重启恢复，不发送个人数据到外部服务。
模型对话专项回归覆盖首页同步、真实 IPC / HTTP 调用、多轮上下文、任务与项目确认、失败重试及模型切换。
干系人专项回归覆盖新建、编辑、移除、取消、空姓名校验、清空列表、原项目数据保留及关闭重启后的 SQLite 恢复。

工作数据保存在 `%APPDATA%\Xiaoyu\workbench.sqlite`。首次启动加载示例项目，
之后的任务、项目修改、收件箱与个人设置会保存在本机。
API Key 使用 Windows 系统安全存储加密后写入数据库。
原附件单独保存在 `%APPDATA%\Xiaoyu\attachments\`，正文与分析记录保存在 SQLite。
SQLite 备份不包含原附件文件夹；完整迁移请正常退出程序后备份整个 `%APPDATA%\Xiaoyu\`。
桌面版可直接请求供应商 API，不依赖 Python 预览服务。

React 已接入桌面渲染入口，现有页面通过兼容层保留，后续逐页迁移。
数据库使用 Electron 自带的 SQLite，避免 Windows 本地模块重编译。
浏览器预览和桌面版目前各自保存数据，不会自动同步。
50 MB Office/PDF 上传在 Windows 桌面版及 `npm run dev:web` 本机预览均可使用；静态 HTML 不提供文件后端。供应商诊断、模型对话、原生浏览器、终端及插件以 Windows 桌面版为准。

### 前端与后端

前端位于 `src/renderer/` 和 `prototype/`，使用 React 入口与已有页面兼容层。
桌面后端位于 `src/main/`，通过隔离的 Electron IPC 处理数据库读写及供应商请求，
数据落在本机 SQLite；运行桌面版无需额外服务器。
`prototype/server.py` 只服务于浏览器预览与 AI 润色代理。
目前没有部署云端后端，也不提供账号登录或跨设备同步。

建议开发环境 Node.js 24 LTS；数据库测试使用其内置 SQLite。

## 预览原型

```powershell
python prototype/server.py
```

或双击根目录的 `start-preview.cmd`。打开：<http://127.0.0.1:8765/>

> `server.py` 同时提供静态文件和 `POST /api/polish` 本地代理。直接使用 `python -m http.server` 也能看原型，但无法调用 DeepSeek。

### 其他设备访问

双击 `start-lan.cmd`，在同一局域网的设备上打开 `http://本机IPv4地址:8765/#/`。
可通过 `ipconfig` 查询本机 IPv4 地址；Windows 防火墙需要允许 Python 的入站连接。
默认 `start-preview.cmd` 仍只监听本机地址。

目标公网地址为 `http://1022szhuli.cn/#/`。启用该地址需要将项目部署到服务器，
再将域名解析到服务器公网 IP；局域网启动不会自动完成公网部署。

### 连接 DeepSeek 润色

1. 到 DeepSeek 开放平台创建 API Key。
2. 打开左下角「个人资料与设置」，在 **DeepSeek API Key** 中粘贴 Key，点「测试连接」。
3. 保存后，在对话输入框点「润色」；预览区会显示 DeepSeek 结果，失败时自动回退本地规则。

浏览器预览的 Key 保存在该浏览器的 `localStorage`。
桌面版使用 Windows 系统安全存储加密，预览服务默认只监听 `127.0.0.1`。

快捷键：

- `Ctrl + Space`：快速捕获
- `Ctrl + K`：命令面板
- `Enter`：对话发送 / 命令面板执行
- `Shift + Enter`：对话换行
- `Esc`：关闭弹层

## 产品主线

1. **收进来**：老板、同事、会议、邮件 → 收件箱。
2. **说清楚**：AI 解析项目、截止、估时、优先级。
3. **排得下**：今日产能条 + 插单影响模拟。
4. **做得完**：必须做 / 应该做 / 可以做。
5. **说得清**：事实层 + 叙述层的日报 / 周报。
6. **看得见**：项目健康度、风险、等待墙、个人画像。
7. **说得动**：对话页直接下指令，确认后写入。
